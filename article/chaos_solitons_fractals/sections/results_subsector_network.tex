\section{Aggregated subsector dependency network}
\label{sec:subsector_network}

Asset-level networks can be difficult to interpret when many share classes and sectors are present. The aggregated subsector dependency network converts ticker-level dependencies into a mesoscopic map. Nodes represent subsectors and edges summarize average dependency strength between subsectors. This is analogous to sector or country aggregation maps used in the financial dependency literature, but adapted to the Brazilian equity universe.

Figure~\ref{fig:subsector_network} presents the resulting network. The network contains 22 subsectors and 66 edges, with density 0.2857. The mean edge dependency is 0.0566 and the median edge dependency is 0.0561. These values are lower than raw asset-level correlations because the network is built after aggregation and filtering, but the topology remains interpretable.

The top degree subsector is Retail, indicating broad direct connectivity in the aggregated dependency map. Electric Utility has the highest betweenness, suggesting that it acts as a bridge in the mesoscopic topology. Apparel and Footwear has the highest weighted degree, reflecting strong dependency intensity across its retained connections. These summaries help translate the abstract PMFG topology into economic language.

The subsector network also provides a useful bridge to forecasting. If network topology contains information beyond univariate volatility persistence, then node-level or group-level centrality measures may help explain future volatility regimes. The forecasting section tests this idea in a conservative first experiment.
